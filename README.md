Face Recognition Attendance System & Smart Curriculum Tracker (Prototype)

Welcome to our Face Detection and Recognition-based Attendance System integrated with a Smart Curriculum Efficiency Tracker. 
This is a naive prototype demonstrating the core functionality of our system using prebuilt libraries and basic AI tools.

🚀 Project Overview

This prototype combines Face Detection, Face Recognition, and Behavioral Analysis to provide:

Automated Attendance System via facial recognition.
Smart Curriculum Monitoring, including:
Sentiment Analysis
Engagement Tracking
Efficiency Analytics

Our goal is to use AI and computer vision to build smarter, automated education systems that not only mark attendance but also help educators understand how effectively students are learning.

🔍 Features

🔒 Face Detection & Recognition using OpenCV / Face Recognition Libraries.
🧠 Sentiment Analysis to understand student reactions during sessions.
📈 Efficiency Tracking based on attention span, expressions, and interaction levels.
🖼️ Live camera feed with real-time detection overlay.


📹 Includes images and videos demonstrating the working of the system.
